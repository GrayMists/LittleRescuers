# Маленькі рятувальники

На станції: вліво/вправо — вибрати машину, A — відкрити гараж, ще раз A — почати завдання.
У завданні: хрестовина — кермувати / наводити, A — дія (тримати — поливати водою тощо).
Start або Select — пауза (A — продовжити, ще раз Start — на станцію).
Вийти з гри — затисни Select + Start на 1 секунду.

Шрифт: Inter (SIL OFL 1.1).
